# Домашнее задание по предмету Системы хранения и обработки данных

### Задание на 4
- Придумать свою бизнесовую систему (например интернет магазин)
- Описать её компоненты: из каких сервисов состоит и что каждый из них делает, имя образа
- Нарисовать диаграмму HLD (С4 container)
- Система должна состоять:
- не менее чем из 3-х сервисов
- внешние зависимости (рест сервисы, источники данных)
- БД
- Очередь сообщений
- Описать сервисы которые будут вне K8S: на каком порту будут работать, на каком IP/DNS и на каком сервере с какими системными требованиями
- По меньшей мере использовать компоненты: Deployment, Ingress, Service, ConfigMap, Secret, Job или CronJob
- Не забыть про request и limit

**На выходе: документ с описанием системы (doc или md) + yaml конфиги в одном файле**
